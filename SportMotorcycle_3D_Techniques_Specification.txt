2. 3D MODELING TECHNIQUES
================================================================================

2.1 Primary Modeling Approaches
- Procedural Modeling (pure code-driven geometry)
- Constructive Geometry / Primitive Composition
- Hierarchical Scene Graph Construction
- Modular Component Assembly (factory pattern)
- Low-Poly / Chunky Stylized Modeling
- Hard-Surface Modeling (mechanical components)
- Organic Panel Sculpting via 2D profile extrusion

2.2 Geometry Generation Techniques
- Shape Extrusion (THREE.Shape + THREE.ExtrudeGeometry)
- Bevel Extrusion (rounded edges via bevelEnabled, bevelSize, bevelThickness)
- Curve-based Modeling (CatmullRomCurve3 + TubeGeometry)
- Parametric Spoke Pattern Generation (5-spoke alloy rims)
- Hole / Cutout Creation (Shape.holes with Path)
- Non-uniform Scaling (e.g. oval exhaust canister)
- Geometry Rotation & Transformation (common on cylinders)
- Deep-dish Rim Construction (stepped cylinders + torus lips)
- Ventilated Brake Disc (extruded shape with central hole + mounting bolts)

2.3 Specific Geometry Types Used
- THREE.CylinderGeometry          (forks, rims, hubs, handlebars, exhaust, etc.)
- THREE.BoxGeometry               (frame spars, engine, calipers, levers, etc.)
- THREE.ExtrudeGeometry           (fairings, tank, seat, tail, fender, vents)
- THREE.TorusGeometry             (tires, rim lips, springs, gaskets, clamps)
- THREE.CapsuleGeometry           (headlight, mirrors, knee recesses)
- THREE.SphereGeometry            (bar-end weights)
- THREE.ConeGeometry              (exhaust intake transition)
- THREE.CircleGeometry            (mirror glass faces)
- THREE.PlaneGeometry             (radiator grille)
- THREE.TubeGeometry              (exhaust header pipe)
- THREE.Shape + THREE.Path        (complex 2D profiles + holes)

5. COORDINATE SYSTEM & PROPORTIONS
================================================================================

- Coordinate Frame:
  +X = Front (headlight, nose, front wheel)
  -X = Rear  (tail, rear wheel, exhaust tip)
  +Y = Up    (ground plane at Y = 0)
  +Z = Right (exhaust, clutch cover, brake disc)
  -Z = Left

- Origin (0,0,0) = Ground plane midpoint between front and rear axles
- Wheel design: Axles at Y ≈ 0.30 so tires touch ground at Y = 0
- Explicit rake angle on steering pivot (~22°)
- Lean-into-turn dynamics based on steering angle + speed

6. RUNTIME / ANIMATION SYSTEM
================================================================================

6.1 sculptRuntime Contract (published on root.userData)
- nodes          : Named Object3D hierarchy
- meshes         : Named Mesh registry
- sockets        : Attachment points (headlight, exhaustTip, riderSeat)
- colliders      : Box3 bounding volumes
- destructionGroups : Fairings / Wheels / Exhaust groupings
- materials      : Material map
- actions        : Public API methods
- animation      : Animation state
- vfx            : VFX sockets

6.2 Public Actions API
- revEngine()
- steer(angle: number)
- setDriveSpeed(speed: number)
- toggleHeadlight(force?: boolean)
- resetPose()

6.3 Per-Frame Tick System (root.userData.tick)
- Smooth steering interpolation
- Body lean / roll based on steering + drive speed
- Wheel rotation (front + rear)
- Engine idle vibration + rev decay
- Headlight emissive breathing pulsation

6.4 Configurable Options
