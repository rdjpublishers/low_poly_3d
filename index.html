Frequently Asked Questions

What does this tool actually do?

Low Poly 3D is a browser-based viewer and editor for a JSON/JS/TS "blueprint" format. It doesn't generate anything by itself — you get the blueprint from your own AI chat, then load it here to render, tweak, and export a low-poly 3D model.

Do I need an API key or account?

No. There's nothing to sign up for and no key to paste in. You use whichever AI chat you already have access to; this app only renders what it's given.

Which mode should I choose?

Start with Standard (JSON) — it works with almost any AI and is easiest to fix by hand if something looks off. Move to Advanced (JavaScript) for more detailed geometry, or Pro (TypeScript) / Pro+ (TSX/JSX) if you want real Three.js code, animation support, and are using a strong coding model.

What's the difference between the "Prompt" and "Image" files?

Use a Prompt_To_* file when you're describing your model in words. Use an Image_To_* file when you're giving the AI a reference picture to turn into a blueprint instead.

Is my data private?

Yes. Blueprints, images, and exports are processed entirely on your device. Nothing you load or build in the viewer is uploaded anywhere.

The AI's output won't load — what now?

Check the Validator panel on the left for the specific error, then paste that error back to your AI and ask it to fix the blueprint. The downloaded file already includes the format rules your AI needs to follow.

Can I edit a model after it loads?

Yes — select any part in the Scene Objects panel to move, rotate, scale, retexture, or delete it, then export as GLB, OBJ, STL, or .ts/.tsx/.jsx.
